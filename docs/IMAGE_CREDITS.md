## Fresh-install behavior

`config/database-public.sql` seeds the Demo administrator and an empty profile, but no pet, news, stray, or image records. These image files are therefore not automatically displayed by a clean installation. The excluded `config/database-demo.sql` contains local demo rows that refer to some images and must not be uploaded; a fresh user creates new records and uploads images through the application.
